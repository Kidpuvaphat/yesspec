# ช่องทางซื้อของ Top 20

เปิด `admin-ranking.html` หรือกด “จัดการ Top 20” จากหลังบ้านเดิม ใช้บัญชีผู้ดูแลเดิมผ่าน Admin API (`admin_server.py`, พอร์ต 3195 / reverse proxy เดิม)

1. เลือกหมวด จะมี 20 รายการตามชุดข้อมูล Shopee เดิม (32 หมวด รวม 640 ตำแหน่ง)
2. เปิดรายการที่ต้องการ กรอกลิงก์ตะกร้า Shopee, Lazada หรือ TikTok Shop แล้วกด “ตรวจราคาจากลิงก์” หรือกรอกราคาเอง เว้นช่องที่ไม่ทราบได้
3. หากพบราคา ให้เลือกตัวเลข ตรวจร้าน/รุ่น/ตัวเลือก ระบุประเภทราคา (ปกติ, VIP / สมาชิก, คูปอง) และติ๊กยืนยัน ปุ่ม “ยืนยันและใส่ราคาในฟอร์ม” เปลี่ยนเฉพาะฉบับร่าง ยังไม่บันทึกหรือเผยแพร่
4. บันทึกรายการเดียวหรือทุกฟอร์มที่แก้ไข แล้วรีเฟรชหน้าเว็บไซต์

มีลิงก์ตะกร้าที่รูปแบบถูกต้องจึงแสดงชื่อช่องทาง ราคา และปุ่มซื้อ ไม่มีลิงก์จะซ่อนทั้งหมด แม้เคยกรอกราคาไว้ หากมีลิงก์แต่ไม่ทราบราคา แสดง “—” ใช้ปุ่ม “ลบลิงก์ / ซ่อนช่องทาง” แล้วบันทึกเพื่อซ่อน Shopee ได้ด้วย ปุ่ม “ใช้ข้อมูลจากฟีด” จะคืนค่า Shopee เดิม

ข้อมูลกรอกเองอยู่ใน `data/ranking_manual_offers.json` แยกจากหลักฐานยอดขายและสเปกเดิม จับคู่ด้วยรหัสร้าน/สินค้า ชื่อ และตัวเลือกในฟีด ถ้าข้อมูลระบุตัวสินค้าเปลี่ยน ช่องทางที่เคยจับคู่ต้องตรวจใหม่ การบันทึกจากแท็บเก่าที่ข้อมูลเปลี่ยนแล้วจะถูกปฏิเสธเพื่อป้องกันทับข้อมูลใหม่ ใช้ “โหลดข้อมูลล่าสุด” เพื่อทิ้งฉบับแก้ไขค้างและเริ่มจากข้อมูลล่าสุด

อันดับยังเรียงตามยอด Shopee ในชุดที่เก็บได้ **ไม่ระบุช่วงเวลา** ไม่รวมยอดข้ามแพลตฟอร์ม ไม่รับรองว่าเป็น Top 20 ทั้งตลาดหรือยอดรายเดือน การเพิ่มราคาต่างช่วงและต่างตัวเลือกไม่ใช้สรุปร้านถูกที่สุด ไม่มีการเปลี่ยนจำนวนรายการหรือเริ่มงานอัตโนมัติรายเดือนในงานนี้

ลิงก์ Shopee ใช้ระบบ Affiliate เดิม ส่วน Lazada และ TikTok เก็บลิงก์และพารามิเตอร์ที่ผู้ดูแลกรอกไว้ตามเดิม จึงควรวาง **ลิงก์ Affiliate จากบัญชีของตนเอง** การวาง URL ทั่วไปไม่ได้สร้างรหัสค่าคอมมิชชันให้อัตโนมัติ: [คู่มือ TikTok สำหรับประเทศไทย](https://seller-th.tiktok.com/university/essay?knowledge_id=1653513000945425&lang=en)

รองรับ URL สินค้าเต็มและลิงก์ย่อที่รู้จัก ตัวตรวจติดตาม redirect เฉพาะโดเมนที่อนุญาต จับคู่รหัสสินค้า แล้วอ่านราคา THB จาก Product/Offer JSON-LD หรือ metadata สินค้าที่ระบุชัดเจน ไม่ประมวลผล JavaScript ไม่เรียก API ภายในแพลตฟอร์ม และไม่ใช้คุกกี้หรือสถานะล็อกอินจาก Chrome ของผู้ดูแล จึงไม่รับประกันว่าจะอ่านได้ทุกลิงก์หรืออ่านราคา VIP ของบัญชีได้

ถ้าพบเพียงช่วงราคา หลายตัวเลือกที่ยังระบุไม่ได้ หน้าล็อกอิน CAPTCHA หรือไม่พบราคาที่ตรงสินค้า ระบบไม่เลือกตัวเลขต่ำสุดแทน ให้ใช้ “เปิดหน้าสินค้า” แล้ว “กรอกราคาเอง” ราคาเดิมยังอยู่จนกว่าผู้ดูแลจะแก้หรือยืนยันใหม่ การตรวจไม่เปลี่ยนลิงก์ Affiliate ที่กรอก และไม่ตรวจสิทธิ์รับค่าคอมมิชชันอัตโนมัติ

ราคาที่อ่านและยืนยันจะเก็บเวลาอ่าน (`price_lookup.checked_at`) กับ URL ต้นทาง/ปลายทางไว้ร่วมกับรายการ หลังบันทึกหน้าเว็บระบุเวลานี้และเตือนเมื่อเกิน 48 ชั่วโมง การแก้ราคา ลิงก์ ตัวเลือก หรือเงื่อนไขเองจะล้างหลักฐานการตรวจ แล้วใช้เวลาบันทึกแบบกรอกเองตามปกติ ข้อมูลนี้แสดงว่าผู้ดูแลยืนยันแล้ว ไม่ใช่การรับรองราคาชำระเงินจริงจากแพลตฟอร์ม

Admin API ต้องทำงานบน origin เดียวกับหน้าเว็บและใช้การล็อกอินเดิม การทดสอบเปิด HTML ด้วย static server อย่างเดียวไม่สามารถบันทึกได้ โค้ดนี้ต้องถูกนำขึ้นเซิร์ฟเวอร์และรีสตาร์ต Admin API จึงจะใช้บนเว็บจริงได้

ปุ่มตรวจเรียก `POST /api/admin/check-ranking-price` ซึ่งต้องมีโทเคนผู้ดูแลและไม่เขียนข้อมูล ต้องนำ `price_check.py`, `admin_server.py`, `ranking_offers.py`, หน้า HTML และ assets ที่เปลี่ยนขึ้นพร้อมกัน ใช้ Python standard library ไม่เพิ่มบริการหรือ dependency ภายนอก ตัวตรวจจำกัดขนาดหน้า จำนวน redirect และเวลารอ พร้อมปฏิเสธปลายทางเครือข่ายภายใน

เมื่อนำขึ้นเซิร์ฟเวอร์ครั้งถัดไป ให้สำรองและเก็บ `data/ranking_manual_offers.json` ที่ผู้ดูแลบันทึกไว้บนเซิร์ฟเวอร์ ห้ามทับด้วยไฟล์ว่างจากชุดติดตั้ง
