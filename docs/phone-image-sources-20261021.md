## ตรวจการทำงาน

- รูป 30/30 โหลดและ decode ใน Chrome สำเร็จ ไม่มีรูปเสีย
- หน้าอันดับและหลังบ้านแสดงรูปตรง 30 listing IDs; หน้าเปรียบเทียบแสดงรูปตามรุ่นที่เลือก
- ทดสอบมือถือ 390×844 และคอม 1365×950 ไม่มีหน้าเลื่อนล้นแนวนอน
- Node 120 รายการผ่าน; Python 83 ผ่านและข้าม 1 รายการที่ไม่มี raw research
- ไม่มีการแก้ราคา ลิงก์ซื้อ สเปก หรือสูตรอันดับ
- ถ้ารูปโหลดไม่ได้แสดงข้อความแทนรูป; ถ้าชื่อรุ่นเปลี่ยนไม่ใช้รูปเดิมอัตโนมัติ
